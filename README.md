Trading Behavior Analysis

This project analyzes user activity and trading behavior to identify key patterns and actionable insights.

Methodology

Cleaned and preprocessed the dataset

Created key metrics for user activity and trade behavior

Used visualizations to compare different user segments

Insights

Inactive users are almost double the active users

Trading patterns differ noticeably across market conditions

Strategy Recommendations

Reduce aggressive trading during fear-driven periods

Focus higher activity strategies on consistently active users
